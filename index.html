Kleos

A media-management dashboard that tracks multiple content creators across YouTube and Twitch from one offline-first SQLite panel.

Python PyQt6 SQLite YouTube / Twitch API AI verification

Why it exists

Running media for 30+ creators across multiple servers means spreadsheets, missed uploads, and payment disputes. Kleos replaces that with a desktop dashboard that keeps every creator's history, stats, and verification status in one place.

Core features

  • Offline-first SQLite databases, one per community profile.
  • Fetches public metadata from YouTube Data API v3 and Twitch Helix.
  • AI verification via Claude or Gemini to classify content against a community description.
  • Keyword verification as a no-AI alternative.
  • Role-filtered creator cards with sparklines, new-activity alerts, and milestone notifications.
  • Leaderboards, analytics charts, and shareable HTML export of community boards.
  • Import/export profiles and creators with merge/dedup.

What it demonstrates

Kleos isn't a config tool I downloaded — it's a full product: API integration, database design, background threading, UI design tokens, and an installer. It shows I can identify a real operational pain point and ship the tool to fix it.

Tech stack

  • Python 3.12+ · PyQt6 · matplotlib · requests · anthropic / google-genai SDKs.
  • Dual-connection SQLite with WAL mode for lock-free reads.
  • PyInstaller packaging into a Windows installer.

Iustitia

A purely client-sided Fabric anti-cheat for Minecraft 1.21.11. It watches other players through server-rebroadcast packets with zero outgoing traffic.

Fabric mod Java / Kotlin 32 detection checks Zero outgoing packets Privacy-first

Why it exists

Most anti-cheats require server installation and broad permissions. Iustitia gives non-staff players a local radar: it detects impossible interactions silently, never bans, never reports, and never sends data anywhere.

Core features

  • 32 checks: 14 combat (reach, killAura, criticals, autoBlock, etc.) and 18 movement/rotation/packet (fly, phase, timer, scaffold, etc.).
  • Read-only packet mixin; fail-open architecture; never crashes the client.
  • Protocol-aware for both 1.8-era and modern 1.21.11 combat via ViaFabricPlus.
  • Local chat alerts with severity scaling; nametag tiers (green/yellow/red) + confidence score.
  • Observer tools: instant replay, .sonar directional audio alerts, evidence clips, moderator notes, and session reports.

What it demonstrates

Iustitia proves I understand cheats at the packet level: how bypasses are built, how server state is rebroadcast, and how to design ethical tooling that detects without enforcing. It also shows systems thinking — a 32-check pipeline with config, keybinds, render overlays, and persistence.

Tech stack

  • Minecraft 1.21.11 · Fabric Loader · Fabric API · fabric-language-kotlin · YACL.
  • Kotlin + Java mixins, Gson config, JDK 21.
  • MIT licensed.
